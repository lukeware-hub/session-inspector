# Roadmap

## 0.1.0: MVP

The framed footer band, the `/inspector` pane with Overview, Context, Session, Activity, Tools, Agents, Files and System, context alerts, cost and rate limits, files touched and lines changed, tool durations and denials, MCP servers, compactions, model speed, and CPU and memory of Claude Code.

## 0.2.0: Git changes and file monitor

Per-file line counts, new untracked files, and which agent edited each file.

## 0.3.0: Agents and subagents

Deeper agent views: the tree of agents and the agents they started, teammates, each agent's own token usage and timeline.

## 0.4.0: Analytics and persistent history

Keep a summary of each session on disk, opt-in, and compare cost, tokens and speed across sessions.

## 0.5.0: MCP and security monitor

Show permission requests and the rule that decided each one, and the MCP servers connected beside the ones used.

## 1.0.0: Stable release

A stable interface, documentation for every section, and support for every surface Claude Code draws on.
